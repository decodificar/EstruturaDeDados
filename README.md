# Estrutura de Dados 📚

Repositório acadêmico para estudo de estruturas de dados e algoritmos em Python.

## Objetivos

- Estudar diferentes estruturas de dados
- Compreender algoritmos associados
- Comparar soluções e analisar trade-offs
- Aplicar conceitos em exercícios práticos

## Organização do projeto

```text
EstruturaDeDados/
├── Aula01/
│   └── RememberingPython.py
├── Aula02/
│   ├── atividade1.py
│   └── e1_maximo.py
├── README.md
└── .gitignore
```

## Conteúdo

### Aula 01
- Revisão e reforço de conceitos fundamentais de Python

### Aula 02
- Exercícios introdutórios e aplicações de lógica e algoritmos

## Como executar

1. Clone o projeto:

```bash
git clone https://github.com/decodificar/EstruturaDeDados.git
cd EstruturaDeDados
```

2. Execute um script Python:

```bash
python Aula01/RememberingPython.py
python Aula02/atividade1.py
python Aula02/e1_maximo.py
```
